# radar-tech-imagens

Slides dos carrosséis do [@juliacardoso.dev](https://www.instagram.com/juliacardoso.dev/)
que já foram **aprovados** para publicação.

Este repositório é público só porque a API do Instagram baixa cada imagem de
uma URL pública na hora de publicar. Ele é preenchido automaticamente pelo
Radar Tech (`python -m radar.espelhar --push`). Não edite à mão: as pastas
espelham o caminho de cada carrossel no repositório de origem.
